# Windows11-VirtualBox-Lab
Built a Windows 11 virtual machine in VirtualBox to learn virtualization, operating system installation, and basic IT lab configuration.

## Overview
This project was created to learn the basics of virtualization and operating system deployment using VirtualBox.

I created and configured a Windows 11 virtual machine on a Windows 10 host system to gain hands-on IT experience in a safe lab environment.
---
## Technologies Used
- VirtualBox
- Windows 11 ISO
- Windows 10 Host Machine
---
## VM Specifications
- 4 GB RAM
- 40 GB Virtual Storage
- NAT Network Adapter
---
## Skills Learned
- Creating virtual machines
- Mounting ISO files
- Installing Windows 11 in a VM
- Configuring virtual hardware
- Understanding host vs guest operating systems
- Basic troubleshooting
---
## Challenges Encountered
### Missing Operating System Error
When first starting the VM, the machine failed to boot because no operating system was installed.
### Solution
Downloaded and mounted a Windows 11 ISO file through VirtualBox storage settings and completed the installation successfully.
